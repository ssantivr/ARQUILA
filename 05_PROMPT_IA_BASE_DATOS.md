# PROMPT IA Y BASE DE DATOS (Backend)

## 1. Directrices Técnicas
- Todo el desarrollo de lógica, modelos y conexiones debe ubicarse en la carpeta `backend/` utilizando **Python**.
- Los nombres de variables, funciones y modelos de datos deben estar estrictamente en **inglés**.

## 2. Paso a Paso de Avances en el Backend
1. **Paso 1:** Diseño de modelos de datos e integración con la base de datos en Python (`backend/`).
2. **Paso 2:** Implementación de controladores, lógica de negocio y patrones estructurales (como Adapter o Bridge).
3. **Paso 3:** Exposición de endpoints limpios y documentados para el consumo del frontend en TypeScript.
4. **Paso 4:** Pruebas unitarias y validación de respuestas del servidor.

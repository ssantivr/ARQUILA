# REQUERIMIENTOS DEL PROYECTO ARQUILA

## Requisitos funcionales

- RF-01: El sistema deberá permitir gestionar las entidades principales del proyecto.
- RF-02: El sistema deberá validar los datos recibidos por la API.
- RF-03: El sistema deberá permitir consultar información mediante operaciones de búsqueda.
- RF-04: El sistema deberá utilizar estructuras de datos apropiadas para las operaciones requeridas.
- RF-05: El sistema deberá persistir la información necesaria en la base de datos.
- RF-06: El sistema deberá exponer endpoints documentados para el frontend.
- RF-07: El sistema deberá incluir pruebas automatizadas de las operaciones principales.

## Requisitos no funcionales

- RNF-01: El código del backend deberá estar escrito en Python.
- RNF-02: El código del frontend deberá estar escrito en TypeScript.
- RNF-03: La lógica de negocio del backend utilizará nombres en inglés.
- RNF-04: El sistema deberá mantener separación entre presentación, lógica, persistencia y estructuras de datos.
- RNF-05: Las operaciones críticas deberán documentar su complejidad temporal y espacial.
- RNF-06: Las credenciales y secretos no deberán almacenarse en el repositorio.

# PROMPT MAESTRO - ARQUILA PROJECT

## Propósito

Define las reglas generales de un proyecto académico de cuarto semestre de Ingeniería de Software.

## Alcance

El contenido de Estructuras de Datos debe limitarse a:

- Arrays.
- Arrays dinámicos.
- Stack.
- Queue.
- Lista simplemente enlazada.
- Lista doblemente enlazada.

## Organización

- `backend/app/data_structures/`: estructuras de datos, implementadas en Python.
- `backend/`: API básica en Python.
- `frontend/`: interfaz en TypeScript.
- `docs/`: documentación en español.
- `.agents/`: reglas del asistente.
- `prompts/`: instrucciones dadas al asistente.

## Reglas de código

El código debe usar identificadores en inglés y no debe contener comentarios ni documentación interna.

## Regla académica

No incorporar árboles, grafos, hash tables, BFS, DFS u otras estructuras avanzadas como parte obligatoria mientras no formen parte del contenido estudiado.

## Desarrollo

1. Definir requisitos.
2. Diseñar la estructura.
3. Implementar.
4. Probar.
5. Integrar.
6. Documentar.
7. Preparar la defensa.

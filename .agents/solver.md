# AGENTE SOLVER

## Propósito

Ayudar en el desarrollo técnico de ARQUILA con un nivel adecuado para cuarto semestre de Ingeniería de Software.

## Reglas

- Mantener el alcance en las estructuras estudiadas.
- Implementar las estructuras de datos en Python, dentro de `backend/app/data_structures/`, sin librerías que las reemplacen.
- Usar inglés para identificadores de código.
- No insertar comentarios ni documentación dentro del código.
- Explicar conceptos técnicos en español fuera del código.
- Preferir soluciones simples y comprensibles.
- No introducir complejidad innecesaria.
- Proponer pruebas pequeñas antes de cambios grandes.
- Mantener separación entre frontend, backend y estructuras de datos.
- Usar solo Python en el backend y TypeScript en el frontend. No añadir otros lenguajes ni herramientas de compilación.

## Prioridad

La comprensión y correcta defensa del proyecto tienen prioridad sobre agregar funcionalidades avanzadas.

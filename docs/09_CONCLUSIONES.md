# CONCLUSIONES

El proyecto ARQUILA debe demostrar que las estructuras de datos y algoritmos no se seleccionan solamente por implementación, sino por las necesidades concretas del sistema.

La arquitectura separa frontend, API, lógica de negocio, estructuras de datos, persistencia y pruebas.

Como resultado final se espera una solución funcional, documentada, comprobable y defendible académicamente.

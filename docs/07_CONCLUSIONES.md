# CONCLUSIONES

ARQUILA se concentra en las estructuras de datos estudiadas actualmente.

El proyecto prioriza una comprensión correcta de arrays, pilas, colas, listas simples y listas dobles.

Las estructuras se implementan de forma independiente para facilitar su análisis, prueba y explicación durante la presentación final.

Las estructuras más avanzadas pueden incorporarse posteriormente cuando formen parte del contenido académico de la asignatura.

# ARQUITECTURA

El proyecto utiliza una separación sencilla de responsabilidades apropiada para un estudiante de cuarto semestre.

```text
Frontend
   |
   v
Backend API
   |
   v
Data Structures
```

## Frontend

Se utiliza TypeScript para representar la interfaz y la comunicación con el backend.

## Backend

Se utiliza Python con FastAPI para exponer servicios básicos.

## Estructuras de datos

Las estructuras estudiadas se implementan en C++ orientado a objetos dentro de `data_structures/`.

Esta separación permite estudiar la materia sin mezclar la implementación académica con la interfaz.

# PLANTEAMIENTO DEL PROBLEMA

ARQUILA es un proyecto académico de cuarto semestre de Ingeniería de Software orientado a demostrar la comprensión práctica de estructuras de datos básicas dentro de una aplicación organizada.

El proyecto busca conectar los conceptos vistos en clase con una estructura de software sencilla, mantenible y fácil de probar.

El alcance se limita a arrays, arrays dinámicos, pilas, colas, listas simplemente enlazadas y listas doblemente enlazadas.
